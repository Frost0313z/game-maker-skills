# 게임 기획서 양식

Witch Dice 기획서(2025, 문서 19개)를 쓴 방식을 그대로 뽑아 만든 양식이다 (2026-11-16 정리).
문서는 세 종류다.

| 종류 | 한 게임에 몇 개 | 하는 일 |
|---|---|---|
| **A. 문서 모음** | 1개 | 게임 개요, 목표 · 일정, 시스템 문서 목차 |
| **B. 시스템 기획서** | 시스템마다 1개 | 개발자(또는 AI)가 이 문서만 보고 구현할 수 있게 |
| **C. 밸런스 기획서** | 1개 | 수치를 왜 그렇게 정했는지, 시뮬레이션과 함께 |

문서 이름은 `[분류] 시스템 이름` 으로 짓는다. 예: `[전투] 주사위 기반 전투 시스템`, `[밸런스] 밸런스 기획`.

## 원본에서 가져온 것과 더한 것

- **원본 그대로**: 문서 이름 규칙, 💡 개요, 문서 히스토리, 기획 의도(why), "다른 선택지 중 이걸 고른 이유", 확장성 고려, 용어 정의, 💡 기능 정의 + 예외), 단계별 계산 예시, 수치표 + 비고, 데이터 테이블 칸 연결, 밸런스의 "조건 → 시뮬레이션 → 문제점 → 보완 계획"
- **더한 것** (AI가 구현하고, 마감 안에 끝내기 위해): A의 기획 의도 · 경쟁작 비교 · 넣는 것 / 안 만드는 것, B의 완료 기준 · 정할 것
