# game-maker-skills — 게임메이커 스킬스

AI와 게임을 만들면서 **자주 하는 일을 절차로 굳혀 둔** Claude Code 스킬 모음.

같은 지시를 두 번 하게 되면, 세 번째부터는 말로 시키지 않고 스킬로 만든다.

스킬의 뼈대는 스마일게이트 퓨처랩의 2주 프로토타이핑 방법론 「인프챌 툴킷」(한 줄 컨셉 → Core Fun → Core Loop → 플레이 테스트 → 피드백 분석 → 다음 스프린트)이다. 이 저장소는 그 단계를 AI와 함께 돌리는 방식 — 사람이 정하고, AI가 덧붙이고 검사하는 방식 — 으로 옮긴다.

## 스킬 목록

| 스킬 | 하는 일 | 상태 |
|---|---|---|
| [core-fun](skills/core-fun/SKILL.md) | 게임의 핵심 재미를 5단계(미학 → 메커닉 → 제약 · 트레이드오프 → 반응 → 한 문장) 인터뷰로 정리. 사용자가 정하고 Claude는 서브 기획자로 아이디어 · 걸리는 점을 덧붙인 뒤 앞뒤를 검사 | 처음 판 |

| 양식 | 하는 일 |
|---|---|
| [게임 기획서 양식](templates/게임-기획서-양식.md) | 문서 모음 · 시스템 기획서 · 밸런스 기획서 세 종류 |

## 설치

스킬 폴더 하나를 `~/.claude/skills/` 아래에 복사하면 Claude Code 가 알아서 읽는다.

```bash
git clone https://github.com/Frost0313z/game-maker-skills.git
cp -r game-maker-skills/skills/<스킬이름> ~/.claude/skills/
```

## 스킬 하나의 모양

```
skills/<스킬이름>/
  SKILL.md        # 필수
```

`SKILL.md` 맨 위에는 이름과 설명을 적는다. 설명에는 **언제 쓰는지**("~해줘" 같은 요청 예시)를 넣어야 Claude 가 알맞은 때에 꺼내 쓴다.

```markdown
---
name: <스킬이름>
description: <무엇을 하는가>. "<요청 예시 1>", "<요청 예시 2>" 같은 요청에 반응한다.
---

# <제목>

1. <첫 단계>
2. <둘째 단계>
3. <끝났는지 확인하는 방법>
```

## 스킬을 더할 때 지키는 것

- **끝났는지 확인하는 단계**를 꼭 넣는다. 결과를 직접 돌려 보고 말하게 한다.
- 개인 정보 · 비밀 키 · 특정 컴퓨터의 경로를 넣지 않는다. 공개 저장소다.
- 한 스킬은 한 가지 일만 한다.
